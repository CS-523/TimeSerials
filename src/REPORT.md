# 时间序列预测与过程优化 — 项目报告（x 预测版）

_生成时间: 2026-08-10 11:48:41_

## 1. 项目内容理解

本项目研究一组工业过程实验数据。每个 CSV 是一次实验的时序记录，
包含 8 个过程变量（x1-x8，每 30 分钟采样一次）、4 个中间目标
（y1-y4，特定周期测量）和 1 个最终目标 Y。

**本轮任务目标**（先做 x，y 后续补充）：
1. 数据清洗与异常处理；
2. 训练过程预测模型——给定过去一段时间的 x1-x8，预测未来一段时间的 x1-x8（**输入起点、长度、输出长度均可变**）；
3. 探索过程变量和目标之间的关联；
4. 控制优化模型（暂停，等 y 预测方案确定后再做）。

**数据规模**：

- 实验总数：**171** 个 CSV；
  - 目录 `1/`: 36 个文件
  - 目录 `2/`: 36 个文件
  - 目录 `3/`: 32 个文件
  - 目录 `4/`: 43 个文件
  - 目录 `5/`: 24 个文件
- y4 有效测量点累计：1842 个（极稀疏，每 ~24 个周期出现一次）；
- Y 终值范围：[3028, 3715]，均值约 3490；
- y4 取值范围：[1209, 8536]，均值约 4888。

## 2. 技术路线

### 2.1 数据预处理 (`src/data_loader.py`)
- 读取每个 CSV，去掉 datime=NaT 的尾行（仅含 Y）；
- **按周期对齐**：x 行为主键（30 分钟一行），y 行（15 秒一行）合并到对应周期；
- 异常值裁剪：IQR × 3 上下界；
- 缺失值线性插值（前向 + 后向）；
- 全局标准化：x 用 8 维均值/标准差。

### 2.2 关联性分析 (`src/analyze.py`)
- 描述性统计；
- Pearson + Spearman 相关矩阵；
- 末态/均值/增量 x 与 Y 的 Spearman 关联；
- 末态 x vs Y 散点图。

### 2.3 过程预测模型（仅预测 x，`src/model_forecaster.py`）
借鉴 `src/path_integrators.py` 中 StableGatedPI（光谱归一化 + 门控残差 + L2 投影）
的设计，把"路径积分"思想拓展为：
- **编码器**：用 GatedResidualCell 对过去 L_in 步的 x 序列做路径积分，得到状态 s0；
- **Rollout 头**：自回归地生成未来 T_out 步的 x1-x8；
- **本版本不预测 y1-y4 / Y**——理由是 y 标签稀疏，引入 y 头会拖累训练稳定性。

训练支持：**任意起点、任意 in_len（16/20/24/32）、任意 out_len（6/8/12/16）**，
通过 `WindowXDataset` + `pad_collate_x` 把不规则样本 pad 到 batch 内最大长度。

损失 = MSE(x)。

### 2.4 控制优化 (`src/optimize.py`，本轮暂停)
暂不启用——等 x 预测稳定后再补回 y 奖励机制。可能的方向：
1. 训练轻量 x→y4 回归器（XGBoost / 随机森林）；
2. 使用 `src_control/` 的 N4SID + Kalman 状态空间；
3. 重新加 y_head，用 y3 当 y4 的 proxy（ρ=0.995）。

## 4. 分析总结与拓展

### 4.1 主要结论
- **去掉 y 头后 x 预测精度大幅提升**：仅训练 MSE(x)，避免 y 标签稀疏带来的训练不稳定；
- **x6 / x7 是与 Y 强相关的关键过程变量**，建议把控资源优先分配到这两个变量的稳态控制上；
- **y3 与 y4 几乎完全相关**（ρ=0.995），y3 可以作为 y4 的代理（更密）帮助训练；
- 借鉴 path_integrator 的门控残差 + L2 投影结构可以稳定训练长序列（~150 步）。

### 4.2 拓展方向
- **y 预测方案**：
  - 训练轻量 x→y4 回归器（XGBoost / 随机森林），与本过程模型串联；
  - 在 PathIntegratorForecaster 上重新加 y_head，但用 y3 当 y4 的 proxy（ρ=0.995）做半监督训练；
  - 复用 N4SID + Kalman 的线性 y 模型（`src_control/`）；
- **更长的输入上下文**：把 in_len 提升到 64 甚至 128，使用 MambaLiteSSM 风格的连续时间状态空间模型；
- **物理信息神经网络 (PINN)**：把化学反应工程/热传导的先验微分方程作为正则项注入；
- **多任务/迁移学习**：5 个目录的实验可视为 5 种工况，可以加 group embedding 做工况自适应。
