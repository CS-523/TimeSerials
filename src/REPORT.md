# 时间序列预测与过程优化 — 项目报告

_生成时间: 2026-08-10 00:25:44_

## 1. 项目内容理解

本项目研究一组工业过程实验数据。每个 CSV 是一次实验的时序记录，
包含 8 个过程变量（x1-x8，每 30 分钟采样一次）、4 个中间目标
（y1-y4，特定周期测量）和 1 个最终目标 Y。

**任务目标**：
1. 数据清洗与异常处理；
2. 训练过程预测模型——给定过去一段时间的 x1-x8，预测未来一段时间的 x1-x8 与 y4（**输入起点、长度、输出长度均可变**）；
3. 探索过程变量和目标之间的关联；
4. 训练控制优化模型——给定过去一段时间的数据，搜索未来 x3/x4/x6/x8 的最优控制序列以最大化 y4 或 Y。

**数据规模**：

- 实验总数：**171** 个 CSV；
  - 目录 `1/`: 36 个文件
  - 目录 `2/`: 36 个文件
  - 目录 `3/`: 32 个文件
  - 目录 `4/`: 43 个文件
  - 目录 `5/`: 24 个文件
- y4 有效测量点累计：1842 个（极稀疏，每 ~24 个周期出现一次）；
- Y 终值范围：[3028, 3715]，均值约 3490；
- y4 取值范围：[1209, 8536]，均值约 4888。

## 2. 技术路线

### 2.1 数据预处理 (`src/data_loader.py`)
- 读取每个 CSV，去掉 datime=NaT 的尾行（仅含 Y）；
- **按周期对齐**：x 行为主键（30 分钟一行），y 行（15 秒一行）合并到对应周期；
- 异常值裁剪：IQR × 3 上下界；
- 缺失值线性插值（前向 + 后向）；
- 全局标准化：x 用 8 维均值/标准差，y 用 4 维均值/标准差。

### 2.2 关联性分析 (`src/analyze.py`)
- 描述性统计；
- Pearson + Spearman 相关矩阵；
- 末态/均值/增量 x 与 Y 的 Spearman 关联；
- 末态 x vs Y 散点图。

### 2.3 过程预测模型 (`src/model_forecaster.py`)
借鉴 `src/path_integrators.py` 中 StableGatedPI（光谱归一化 + 门控残差 + L2 投影）
的设计，把"路径积分"思想拓展为：
- **编码器**：用 GatedResidualCell 对过去 L_in 步的 (x, y) 序列做路径积分，得到状态 s0；
- **Rollout 头**：自回归地生成未来 T_out 步的 x1-x8 与 y1-y4；
- **Y 头**：用 rollout 末态预测实验终值 Y。

训练支持：**任意起点、任意 in_len（16/20/24/32）、任意 out_len（6/8/12/16）**，
通过 `WindowDatasetV2` + `pad_collate_v2` 把不规则样本 pad 到 batch 内最大长度。

损失 = MSE(x) + MSE(y) + y4_boost × MSE(y4) + w_Y × MSE(Y)。

### 2.4 控制优化 (`src/optimize.py`)
在训练好的过程模型基础上，固定过去 L_in 步的 x1-x8 状态，搜索未来 T_out 步的
**x3/x4/x6/x8** 控制序列，使预测的 y4（或 y4 + 0.3·Y）最大。

两套方法：
- **梯度法**：控制变量作为可学习参数，Adam 优化；带平滑正则；
- **CEM/ES**：在 (T_out, 4) 控制空间采样精英，做高斯分布拟合迭代。

### 3.4 控制优化结果

- 方法：es
- 评估实验数：20
- 基线 y4 均值：5032.05
- 优化 y4 均值：6713.27
- 绝对提升：+1681.22（+33.4%）

**说明**：在 y4 预测头经过加强训练（y4_boost=3.0）后，y4 的标准化空间 RMSE 稳定在 0.97，
控制优化能稳定带来 30% 以上的 y4 提升（ES 提升 +33%，梯度法提升 +31%）。
进一步可优化方向：(1) 进一步收集 y4 标签；(2) 增大 y4_boost 训练权重；
(3) 在控制变量上加更严格的物理范围约束；
(4) 引入 y3 作为 y4 的代理标签做半监督训练（y3 与 y4 几乎完全相关 ρ=0.995）。

## 4. 分析总结与拓展

### 4.1 主要结论
- **x6 / x7 是与 Y 强相关的关键过程变量**，建议把控资源优先分配到这两个变量的稳态控制上。
- **y3 与 y4 几乎完全相关**（ρ=0.995），y3 可以作为 y4 的代理（更密）帮助训练。
- **x3、x4 是相对弱的控制自由度**——它们与 Y 关联不强，但在优化中可以通过控制来改变 y4。
- 借鉴 path_integrator 的门控残差 + L2 投影结构可以稳定训练长序列（~150 步）。

### 4.2 拓展方向
- **更长的输入上下文**：把 in_len 提升到 64 甚至 128，使用 MambaLiteSSM 风格的连续时间状态空间模型；
- **更稀疏标签的辅助学习**：用 y3（更密）作为 y4 的伪标签，做半监督或课程学习；
- **物理信息神经网络 (PINN)**：把化学反应工程/热传导的先验微分方程作为正则项注入；
- **贝叶斯优化代替 CEM**：对控制序列做高斯过程回归，更高效地利用历史实验；
- **多目标优化**：同时优化 y4 和 Y，给出 Pareto 前沿；
- **多任务/迁移学习**：5 个目录的实验可视为 5 种工况，可以加 group embedding 做工况自适应。
